# HoodRain

🌧️ Make it rain ETH on your holders.

HoodRain is the first ETH distribution protocol on Robinhood Chain.

Anyone can deposit ETH and distribute it proportionally to all holders\
of any token — in minutes, with no custom code required.

→ One script reads all holders\
→ One transaction deposits the ETH\
→ Every holder claims their share directly to their wallet

1% fee · 30-day claim window · No custodial risk · Verified on-chain
